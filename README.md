# 🤖 Chatbot Tensor -  

"Chatbot inteligente basado en TensorFlow para automatizar respuestas de contacto").

## 🚀 Características
* 🧠 Red nueronal densa (PLN) usando TensorFlow.
* 💬 Respuestas basadas en lenguaje personalizado.
* ⚡ API rápida integrada con [ Django, Js ]

> [!IMPORTANT]
## 🛠️ Requisitos Previos
Antes de comenzar, asegúrate de tener instalado:
* Python 3.12 
* Pip (administrador de paquetes de Python)

> [!NOTE]
## 📦 Instalación y Configuración

1. **Clona el repositorio:**
   * Ejecuta el comando: 
   git clone git@github.com:andrehw/BOT.git


2. **Crea un entorno virtual:**
  
   python -m venv venv
   # En Windows (PowerShell):
   .\venv\Scripts\Activate.ps1
  

3. **Instala las dependencias:**
   * Ejecuta el comando:
